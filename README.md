# remoteControl

基于 **C++ / Win32 API / Winsock** 实现的 Windows 局域网远程控制程序。由「被控端（服务端）」和「控制端（客户端）」两部分组成：控制端实时显示被控端的屏幕画面，并将本地的鼠标、键盘操作发送到被控端执行，实现类似远程桌面的效果。

> 本项目用于学习 Windows 网络编程与图形编程，仅限在**自有设备、局域网内、经过授权**的场景下使用。

## 功能特性

- 🖥️ **屏幕实时传输**：被控端通过 `BitBlt` 抓屏，经 `CImage`/GDI+ 编码为 PNG 后通过网络流发送，控制端解压并在窗口中绘制显示。
- 🖱️ **鼠标远程控制**：支持移动、左/中/右键按下、抬起、单击、双击，坐标按窗口与远程屏幕比例自动换算。
- ⌨️ **键盘远程控制**：捕获按键虚拟码并转发到被控端，通过 `SendInput` 模拟按键。
- 🧵 **服务端多线程处理**：屏幕、鼠标、键盘三类命令各自使用独立的线程（Windows 消息队列）异步处理。
- 🧩 **自定义通信协议**：简单的二进制包结构（包头 + 命令号 + 长度 + 数据），支持粘包/拆包解析。

## 项目结构

```
remoteControl/
├── remoteControl.slnx          # 解决方案（Visual Studio .slnx 新格式）
├── client/                     # 控制端（客户端）
│   ├── client.cpp              # 主程序：Win32 窗口 + 远程画面显示 + 输入捕获
│   └── client.vcxproj
└── remoteControl/              # 被控端（服务端）
    ├── remoteControl.cpp       # 主程序：抓屏、模拟鼠标/键盘、网络收发
    └── remoteControl.vcxproj
```

| 项目 | 角色 | 说明 |
| --- | --- | --- |
| `remoteControl` | 被控端（服务端） | 运行在**被控制**的电脑上，监听端口并接收控制指令 |
| `client` | 控制端（客户端） | 运行在**发起控制**的电脑上，显示远程画面并发送输入事件 |

## 通信协议

自定义二进制包结构，所有字段按 1 字节对齐：

```
+--------+--------+----------+--------+
| magic  |  cmd   | body_len |  body  |
| 4 字节 | 4 字节 |  4 字节  | 变长   |
+--------+--------+----------+--------+
```

- `magic`：包头魔数，固定为 `0x55AA77CC`
- `cmd`：命令号
- `body_len`：数据体长度
- `body`：数据体（可为空）

命令号定义：

| 命令 | 值 | 含义 |
| --- | --- | --- |
| `CMD_SCREEN` | 1 | 屏幕画面数据 / 请求截屏 |
| `CMD_MOUSE` | 2 | 鼠标事件 |
| `CMD_KEYBOARD` | 4 | 键盘事件 |
| `CMD_TESTCONNECT` | 2026 | 连接测试 |

## 环境要求

- 操作系统：Windows 10 / 11
- 开发工具：Visual Studio 2022（工具集 `v145`，项目为 `VCProjectVersion 18.0`）
- 语言标准：C++20
- 平台：x64（解决方案也声明了 x86 配置，但以 x64 为主）
- 依赖：`ws2_32.lib`（Winsock）、ATL（`atlimage.h`）、GDI+

## 编译与运行

1. 使用 Visual Studio 2022 打开 `remoteControl.slnx`。
2. 选择 `x64` + `Debug`（或 `Release`）配置。
3. 分别编译两个项目，得到 `remoteControl.exe`（被控端）和 `client.exe`（控制端）。

## 使用说明

1. **配置 IP 地址**：在部署前，将服务端与被控端代码中**硬编码的服务器 IP** 改为被控端电脑的实际局域网 IP：
   - 服务端 `remoteControl.cpp` → `InitServer()`：`inet_addr("192.168.229.128")`
   - 客户端 `client.cpp` → `InitSocket()`：`inet_addr("192.168.229.128")`
2. **启动被控端**：在被控制电脑上运行 `remoteControl.exe`，程序监听端口 `9999`。
3. **启动控制端**：在控制电脑上运行 `client.exe`，连接成功后窗口即显示被控端屏幕。
4. 在控制端窗口内移动鼠标、点击、按键，即可远程操作被控端。

## 已知限制 / 待改进

- 服务器 IP 与端口（`9999`）目前为**硬编码**，建议改为可配置项（配置文件或命令行参数）。
- 屏幕传输为单帧 PNG 全量发送，无增量编码 / 压缩优化，帧率与带宽占用仍有较大提升空间。
- 客户端鼠标移动事件发送频率较高（未启用注释中的限频逻辑），可能影响整体帧率。
- 键盘仅处理按键按下（`WM_KEYDOWN` / `WM_SYSKEYDOWN`），未处理抬起事件。
- 网络收发缺少健壮的错误处理与断线重连逻辑。
